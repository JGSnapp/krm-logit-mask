Компетенции из резюме —
без каталога в промпте.

Модель не видит названий компетенций. Она пишет ключевые слова резюме, а маска разрешает только слова каталога, связанные одной фразой. Найденных кандидатов модель проверяет простым вопросом и подтверждает дословной цитатой.

  1. Поиск по словампары слов из одной фразы КРМ, пересечение компетенций → пул кандидатов
  2. Проверка вопросом«Имеет ли кандидат указанную компетенцию?» — ДА / НЕТ, по одному кандидату
  3. Цитата«Выведи из текста цитату, подтверждающую её больше всего» — дословно, под маской
