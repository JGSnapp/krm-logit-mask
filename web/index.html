Компетенции из резюме —
без каталога в промпте.

Модель не видит названий компетенций. Она пишет ключевые слова, а маска разрешает только слова каталога, связанные одной фразой. Найденных кандидатов модель проверяет простым вопросом, каждая компетенция подтверждается дословной цитатой из резюме.

Цитата сначала

  1. Цитатымодель выбирает предложения резюме, которые показывают навык или опыт
  2. Поиск по каждой цитатеслова каталога по короткому фрагменту → группа компетенций
  3. Проверка вопросом«Имеет ли кандидат указанную компетенцию?» — ДА / НЕТ

Цитата в конце

  1. Поиск по резюмепары слов из одной фразы КРМ по всему тексту → пул кандидатов
  2. Проверка вопросом«Имеет ли кандидат указанную компетенцию?» — ДА / НЕТ
  3. Цитата«Выведи из текста цитату, подтверждающую её больше всего» — дословно
01

Профиль кандидата

Первый запуск на каталоге загружает модель и строит словарь каталога. Это занимает до минуты, дальше быстрее.

Модель ищет кандидатов, проверяет их и подбирает цитаты…

Цитаты и найденные к ним компетенции

Сначала модель выбрала предложения резюме, которые показывают навык или опыт. Поиск по словам шёл по каждому предложению отдельно; рядом — уверенность проверки по каждой найденной компетенции.

03

Все кандидаты поиска

Порядок — по уверенности ответа на вопрос. Уверенность = log P(ДА) − log P(НЕТ): выше нуля — модель отвечает «ДА»; около нуля — слабое «ДА». «Место» — позиция в выдаче поиска (в режиме «цитата сначала» — номер цитаты, по которой найдено).
